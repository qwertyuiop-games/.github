# qwertyuiop Games

## About us

### We ❤️ open source

We are a open source project that uses the GPL v3 license to create game creation software.

### Our own games

We also make our own games that are accesible through our [launcher](https://qwertyuiop-games.github.io/launcher/).

## Our projects

### Our tools

#### [A Game Launcher](https://qwertyuiop-games.github.io/launcher/)

A website where we share *our own* games so you don't need to download **anything!**

#### [A Sound Effect Library](https://qwertyuiop-games.github.io/sfx-lib/)

A *tiny* but usefull sound effect library where all sfx can be used commercially.

#### [A project info TUI](https://github.com/qwertyuiop-games/project-info)

A python scripts where you get valueble information about your project.

#### [A Project Generator](https://github.com/qwertyuiop-games/project-gen/)

A script for MacOS, Linux and Windows that generates a project; we use this structure for our own games.

### Our games

#### [Find the Password](https://qwertyuiop-games.github/find-the-pwd/)
